# Bibliotecas de mensajería

La recepción e interpretación de MMS utiliza Android SMS/MMS de Jacob Klinker (5.2.6),
que incluye componentes del Android Open Source Project, bajo licencia Apache 2.0.

- Proyecto y licencia: https://github.com/klinker41/android-smsmms
- Texto de Apache 2.0: https://www.apache.org/licenses/LICENSE-2.0

La recepción diferida utiliza AndroidX WorkManager (Apache 2.0).
Las pruebas de componentes Android utilizan Robolectric (MIT).
